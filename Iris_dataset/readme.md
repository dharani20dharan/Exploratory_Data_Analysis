# Iris Data Preprocessing & Visualization

## Objective
Perform preprocessing and visualization on the Iris dataset.

## Steps
1. **Handle Missing Values** – Used `SimpleImputer` with mean strategy.  
2. **Normalize Data** – Applied `MinMaxScaler` for feature scaling.  
3. **EDA** – Checked counts, mean, std, and data types.  
4. **Visualization** – Created histograms and scatter plots for feature comparison.

## Plots
- Histogram of Sepal Width  
- Histogram of Petal Width  
- Scatter: Petal Length vs Sepal Width  
- Scatter: Sepal Length vs Sepal Width  
- Scatter: Petal Length vs Petal Width

## Libraries
NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
