#  Exploratory Data Analysis Projects

This repository contains four Exploratory Data Analysis mini-projects built using Python and Scikit-learn.  
Each folder includes the dataset, Jupyter notebook, and a project-specific README.

---

##  Projects
- **Epileptic_Seizure_Dataset** – EEG signal classification using Random Forest & SVM  
- **Hitters_Dataset** – Player salary prediction using regression models  
- **Iris_Dataset** – Flower classification using multiple ML algorithms  
- **MNIST_Dataset** – Handwritten digit recognition using SGDClassifier  

---

##  Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
